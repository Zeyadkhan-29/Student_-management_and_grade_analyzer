# 🎓 Student Management & Grade Analyzer

A Python-based application for managing student records and analyzing academic performance.

The project focuses on student data management, grade calculation, and performance analysis using Python fundamentals and built-in data structures.

---

## 📌 Features

### 👨‍🎓 Student Management

* Add student details
* Store student records
* View student information
* Search for a student
* Update student information
* Delete student records

### 📊 Grade Analysis

* Store marks for different subjects
* Calculate total marks
* Calculate average marks
* Determine grades
* Check pass/fail status
* Find highest and lowest marks

### 📈 Performance Analysis

* Calculate class average
* Identify the highest-performing student
* Identify the lowest-performing student
* Analyze individual student performance

## ⚙️ How It Works

The application allows users to manage student information and analyze their academic performance.

Example student record:

```text
Student ID: 101
Name: Rahul

Mathematics: 85
Physics: 78
Python: 92
English: 81
```

The system can calculate:

```text
Total Marks: 336
Average: 84.0
Grade: A
Status: Pass
```
